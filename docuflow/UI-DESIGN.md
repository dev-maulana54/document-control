# Penyempurnaan UI Docuflow

## Tujuan dan batasan

Pengguna dapat membuka aplikasi langsung dari `document-control/index.html` atau `docuflow/index.html`, masuk sesuai peran, menemukan dokumen terbaru, dan melihat pekerjaan yang perlu ditinjau. HTML, CSS, dan JavaScript tetap tanpa framework. Model localStorage dan akun yang sudah tersimpan dipertahankan.

## Kontrak desain

- Pertahankan identitas biru: navigasi navy, aksi utama biru, permukaan putih, latar abu kebiruan. Status selalu memiliki teks, bukan hanya warna.
- Home langsung menampilkan kategori, panduan Alur Pengendalian Dokumen, dan aktivitas berisi nomor dokumen, judul lengkap, revisi, serta tanggal pembaruan. Kolom pencarian header pada Home, banner biru, dan empat kartu ringkasan dihapus. Sidebar memakai logo `cbi.png`, nama PT Century Batteries Indonesia, dan Document Control tanpa latar putih; halaman login tetap memakai identitas semula.
- Gunakan Plus Jakarta Sans, teks isi 13–14px, label 12px, metadata tabel 10–12px, judul halaman 28px. Skala jarak 4/8/12/16/24/32px dan radius 6/8/12px.
- Tabel: nama dan nomor dokumen berhierarki jelas, toolbar filter, aksi berlabel, pagination. Di layar kecil, daftar dokumen menjadi baris bertumpuk tanpa memotong metadata dan tombol.
- Daftar dokumen memakai delapan kolom: No, Nama Dokumen, Nomor Dokumen, Jenis Dokumen, Departement, Revisi, Tanggal Efektif, dan Aksi (View/Edit/Delete). No mengikuti pagination dan diulang dari 1 pada hasil filter. Filter jenis dan departemen berupa combobox yang dapat diketik, mendukung ArrowUp/ArrowDown/Enter/Escape, serta menyisakan jarak untuk ikon panah. Filter status dihapus dari seluruh daftar. Reset filter memiliki ikon.
- Logo sidebar berada di kiri teks perusahaan. Document Control berada tepat di bawah nama perusahaan, dengan latar sidebar navy. Submenu dokumen tanpa garis dan titik timeline. Bantuan sidebar dan pencarian header dihapus; daftar dokumen tetap memiliki pencarian dan filter. Submenu aktif memakai latar primary biru dengan teks putih.
- Halaman daftar tidak memiliki slogan atau tombol ekspor. Master Dokumen admin memiliki tombol Tambah Dokumen pada header untuk membuka modal formulir tanpa berpindah halaman; halaman jenis dan Semua Dokumen tidak memiliki tombol tersebut. Modal menggunakan validasi, pilihan jenis, departemen/seksi, dan penyimpanan yang sama dengan form utama. Fokus masuk ke nama dokumen; simpan menutup modal dan memperbarui daftar; Batal/Escape menutup modal. Menu admin Jenis Dokumen mengelola nama dan kode awalan, lalu menyinkronkan sidebar/kategori/filter/formulir. Id jenis tetap saat rename; jenis terpakai dilindungi dari penghapusan; data lama dimigrasikan secara aditif. Role user membuat dokumen melalui Create / Revise dan tidak memiliki tombol Delete atau Tambah Dokumen di Master.
- Formulir: satu tombol Simpan Dokumen tanpa alur status/review. Tidak ada kolom deskripsi atau catatan nomor otomatis. Label tanggal menjadi Tanggal Efektif, revisi ditampilkan mulai 0 tanpa padding. Semua select pada formulir ditingkatkan menjadi combobox pencarian dengan label, validasi, dan navigasi keyboard. Pilihan seksi selalu mengikuti departemen. Nilai select asli tetap dipakai untuk penyimpanan; teks pencarian tidak menjadi nilai bebas.
- Edit membuka modal Update Dokumen pada halaman yang sama untuk memperbarui metadata atau mengganti PDF. Id, nomor dokumen, revisi, dan riwayat versi tetap; file dipertahankan jika tidak memilih pengganti. Create / Revise khusus membuat dokumen baru (revisi 0) atau versi berikutnya (+1 dengan id baru dan nomor sama). Penanggung jawab dihapus dari formulir dan detail; ownerId tetap internal untuk izin.
- Lonceng dan notifikasi dalam aplikasi dihapus. Pencarian penerima hanya untuk metadata Notifikasi Email non-IK, dengan status pengiriman belum aktif. IK tidak memakai penerima email. Tidak menampilkan klaim email terkirim sebelum layanan tersedia.
- Lampiran hanya PDF maksimal 2 MB, dengan validasi ekstensi dan header file. Preview sebelum simpan tersedia setelah file lolos validasi. PDF disimpan sebagai Base64 dalam localStorage saat dokumen disimpan; View membuka PDF tersimpan di tab baru, sementara nama dokumen membuka detail. Detail juga menyediakan Preview PDF. Tab preview memakai Blob PDF dan tidak memiliki akses opener. Penyimpanan yang melebihi kuota mempertahankan data lama serta membiarkan formulir terbuka.
- Preview memiliki halaman sendiri tanpa header atas, tombol unduh, atau revisi. Footer menampilkan nomor dan judul dokumen menggantikan nama file; judul panjang dipotong secara visual dengan teks lengkap pada tooltip. Nomor yang sudah tersedia ikut dikirim saat preview file pengganti di formulir update/revisi. Nama perusahaan disembunyikan pada layar kecil agar metadata tetap muat. Pembaca native browser berada dalam iframe; toolbar navy melayang menyediakan Zoom out/in (25–300%), Sesuaikan halaman, dan Full view. Target sentuh 38–40px dan fokus keyboard jelas; kontrol tetap muat 320px. Pesan handoff dicek sumber/origin/token dan izin terkini sebelum byte PDF dikirim; Blob dibuat oleh tab preview dan dilepas saat tutup. Preview tetap berfungsi setelah aplikasi utama di-refresh. Mode layar penuh mengikuti izin browser dengan pesan kegagalan; membuka viewer langsung menampilkan cara membuka PDF yang benar. Zoom memuat ulang PDF sehingga tampilan kembali dari awal.
- Identitas yang terlihat memakai PT Century Batteries Indonesia. Pencarian penerima tidak menampilkan nama sebelum pengguna mengetik; hasil berupa dropdown checkbox dengan pilihan banyak nama. Chip mempertahankan pilihan lintas pencarian. Escape/klik luar menutup hasil, ArrowDown memindahkan fokus ke hasil, dan Space memilih checkbox.
- Kategori dokumen terpisah dari jenis; lima kode OM tersedia awal. Admin memiliki halaman Kategori Dokumen dan Otorisasi Dokumen. Otorisasi berupa tabel data kategori per departemen dengan pencarian dan checkbox izin dengan deny-by-default; salin menggunakan sumber tersimpan ke beberapa tujuan dan menjelaskan bahwa izin tujuan diganti. Dokumen lama memakai kategori LEGACY melalui migrasi sekali. Pemindahan kategori berlaku untuk seluruh revisi dengan nomor yang sama. Rincian dan batasan keamanan prototipe ada di SPEC-document-access.md.
- Navigasi: halaman aktif ditandai, skip link, Escape menutup menu seluler, fokus tidak keluar dari menu seluler yang terbuka. Dialog memakai elemen native `dialog` dan nama aksesibel.
- Login: satu judul utama, formulir sederhana, panel visual berupa contoh alur pengendalian dokumen, akun demo jelas. Font eksternal gagal tetap memiliki fallback.
- Excel: admin mengunggah template per jenis; simpan IK membuat salinan lalu membuka editor. Nilai sel dapat diedit, formula tetap hanya-baca dengan hasil tersimpan, dan format template dipertahankan pada file. Lembar tersembunyi tidak dirender. Detail dan batasan ada di SPEC-spreadsheet-workflow.md.
- Wajib diperiksa pada 320, 768, 1024, dan 1440px; navigasi keyboard, empty/error/success states, kontras, console browser, dan alur role.

## Referensi

Struktur toolbar, pengelompokan informasi, label formulir, dan konsistensi kontrol ditinjau dari dokumentasi resmi, lalu disesuaikan dengan sistem visual Docuflow:

- [Carbon Data Table](https://www.carbondesignsystem.com/building-blocks/core/components/data-table/guidelines)
- [Carbon Text Input](https://www.carbondesignsystem.com/building-blocks/core/components/text-input/guidelines)
- [Chromium PDF open parameters](https://raw.githubusercontent.com/chromium/chromium/main/chrome/browser/resources/pdf/open_pdf_params_parser.ts) — parameter zoom/view pada navigasi PDF.
- [MDN requestFullscreen](https://developer.mozilla.org/en-US/docs/Web/API/Element/requestFullscreen) — layar penuh dari aksi pengguna dan penanganan penolakan browser.
- [Atlassian Navigation](https://atlassian.design/components/navigation-system/) — halaman referensi tidak menyediakan konten teks; keputusan navigasi mengikuti sidebar Docuflow yang sudah ada.

## Verifikasi versi sebelumnya (perilaku saat itu)

Perluasan area Excel: default 100 baris/26 kolom, tambah 50 baris/10 kolom hingga 1.000/100. Uji browser lulus untuk ukuran kosong tersimpan, AT220 dan CV1000, refresh, unduh, merge yang melintasi jendela render, formula/style/gambar tetap utuh, batas maksimum, akses baca, dan 320/768/1024/1440px. Pada sheet logis 100.000 sel, pengujian memasang 9.901 textarea saat posisi awal; baris lain dirender ketika digulir.

Alur Excel terbaru: pemeriksaan sintaks 11 skrip, 19 tes Node, dan audit dependency tanpa temuan. `python tests/browser-workbook.py` lulus untuk template admin, role user, form IK tanpa lampiran/email, editor/merge/style/gambar/rumus, roundtrip ZIP, template asli, refresh, revisi independen, pembatasan kategori, XML invalid, dimensi worksheet kosong, cleanup file, dan Back browser. Tampilan diperiksa pada 320/768/1024/1440px; file entrypoint lokal lulus. Tidak ada error console atau permintaan eksternal pada alur utama. Hasil notifikasi lama di bawah merupakan catatan verifikasi sebelum fitur dalam aplikasi dihapus.

Perbaikan klik penerima: pointer pada label mempertahankan fokus di dalam picker. Klik nama/email/area baris kini memanggil pemilihan penerima secara eksplisit dan membatalkan aktivasi label bawaan agar tidak terjadi toggle dua kali. Klik checkbox langsung dan Space tetap memakai event change. Pemeriksaan tanpa aktivasi label bawaan lulus. Uji Chrome/Edge 1440/768px dan sentuhan 320px lulus untuk nama, email, area baris, checkbox langsung, pilih/batal pilih satu kali, banyak penerima, pencarian berganti, Escape, ArrowDown/Space, hapus chip, klik luar, dan penerima yang tersimpan. Dua belas tes proyek dan pemeriksaan sintaks lulus; console tanpa error/peringatan.

Perubahan kategori/otorisasi: 12 tes otomatis dan pemeriksaan sintaks lima skrip lulus. Browser terisolasi memverifikasi izin departemen, salin ke beberapa tujuan, salinan independen, sumber kosong, larangan akses milik sendiri setelah izin dicabut, notifikasi tanpa izin, CRUD kategori, pemindahan seluruh versi, preview file pengganti dengan nomor yang sama, dropdown penerima dengan checkbox/chip/keyboard, dan pembukaan file lokal. Layout otorisasi lulus 320/768/1024/1440px; dropdown penerima lulus 320/768px. Tidak ada error JavaScript atau peringatan console pada pengujian tambahan. Hasil audit axe yang tercatat di bawah berasal dari verifikasi sebelumnya.

Uji pembukaan HTML lokal dan HTTP, login admin/user, sesi setelah refresh, filter, detail dan Escape pada dialog, Simpan Dokumen dan revisi langsung, serta navigasi seluler. Jalankan audit aksesibilitas otomatis sebagai pelengkap pemeriksaan visual dan keyboard.

Hasil: pembukaan file lokal dan HTTP lulus; tidak ada overflow halaman pada 320/768/1024/1440px; alur admin dan user lulus; tidak ada error JavaScript. Audit axe-core untuk WCAG A/AA pada login, dashboard, formulir, empty state, dan daftar seluler lulus tanpa pelanggaran. Pengujian memakai profil Chrome terisolasi melalui Playwright karena Chrome DevTools MCP tidak tersedia pada sesi ini.

Verifikasi Update/preview/notifikasi: Update mempertahankan id/nomor/revisi/riwayat dan mengganti PDF; tanpa file pengganti PDF tetap sama. Create / Revise menghasilkan versi baru. Tambah Dokumen mulai revisi 0, kirim ke dua penerima, pencarian penerima, Batal, migrasi data lama, PDF palsu, dan kegagalan kuota lulus. Akun penerima hanya melihat notifikasinya dan memiliki status baca terpisah. Preview tab baru lulus uji zoom native 100%→125%→100%, fit, masuk/keluar fullscreen, unduh, dan refresh aplikasi utama pada file lokal maupun HTTP. Audit axe pada modal Update, daftar/notifikasi, viewer normal/error, dan daftar seluler lulus tanpa pelanggaran A/AA. Lima pemeriksaan aset lokal dan pemeriksaan sintaks kedua skrip lulus.


## Permintaan dan editor (2026-11-15)
Create / Revise membuka tabel permintaan terpisah dari daftar Dokumen. Tombol Buat Permintaan menuju form; Simpan membuat draft dan membuka salinan template. Halaman permintaan menampilkan status, versi isi, daftar approver, keputusan per orang, catatan pengembalian, riwayat putaran, dan aksi admin Terbitkan. Semua approver wajib setuju tanpa urutan. Isi dikunci ketika diajukan; editor resmi selalu hanya baca. Ajukan Update mengarah ke draft revisi, bukan modal edit versi resmi.
Toolbar Excel menggunakan kontrol native berlabel, dibungkus pada layar kecil; grid tetap bisa digeser. Rentang diketik atau Shift+klik, lalu font/warna/perataan/border/merge/format angka berlaku pada pilihan. Undo/redo dibatasi riwayat dalam sesi. Rumus template tetap hanya baca dengan hasil cached dan keterangan batas fitur.


## Ribbon dan area 1.000x1.000
Referensi user adalah ribbon Excel Home. Antarmuka mengikuti kelompok Clipboard, Font, Alignment, Number, Cells, Editing, ikon format, dan satu baris name box/fx/formula bar. Branding perusahaan dipertahankan. Hanya tab Home dan View yang berfungsi ditampilkan; kalkulasi rumus penuh dan fitur desktop lain tidak diklaim. Pada ponsel ribbon dapat digeser horizontal tanpa membuat halaman melebar.
Virtualisasi dua sumbu memasang sekitar 1.257 textarea untuk satu juta sel logis pada desktop 1918x1100. Uji buka editor mencatat 225-287 ms dalam browser lokal (termasuk membuat draft); angka ini bukti sintetis lokal, bukan jaminan perangkat lain. Sel ALL1000, merge yang terpotong pada dua sumbu, simpan/refresh/export, clipboard, navigasi Tab, empat lebar layar, dan approval lulus.


## UX editor dan Insert
Simpan permintaan kembali ke tabel. Edit Excel memakai tombol disabled saat status sudah diajukan; Lihat Excel membuka mode baca eksplisit. Workspace Excel lepas dari sidebar/topbar/footer aplikasi agar grid lebih luas, dengan identitas dokumen dan aksi kembali/simpan/unduh tetap tersedia. Seleksi menyerupai Excel: anchor putih, area abu transparan, batas hijau, header tersorot, drag serta autoscroll. Header kolom hanya menggeser horizontal, baris hanya vertikal. Fokus setelah format kembali ke anchor; formula bar dipakai jika anchor tidak terpasang dalam viewport. Font searchable memakai listbox portal dengan Arrow/Enter/Escape; ukuran angka mendukung desimal. Tab Insert menyediakan Pictures, Text dan Symbol yang benar-benar tersimpan dalam XLSX.

Tab worksheet ditempatkan di bawah grid dan scrollbar horizontal, sebelum bantuan singkat. Posisi ini berlaku pada editor dan mode baca; ribbon tetap di atas.

Baris info jumlah baris/kolom dan bantuan di bawah grid dihapus; tab worksheet menjadi baris terakhir panel.
