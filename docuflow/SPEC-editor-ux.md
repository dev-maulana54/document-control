# Tabel permintaan dan pengalaman editor Excel

Kontrak mengikuti permintaan user: data Create/Update masuk tabel, aksi Edit Excel dari tabel nonaktif setelah submit, viewer/editor memakai ruang tanpa sidebar/header aplikasi, drag area dan header, ketik langsung setelah memakai alat, font searchable dan ukuran bebas ketik, serta tab Insert untuk gambar/simbol.

- Simpan membuat/memperbarui `documentRequests` dan menuju `#requests`. Tabel mempunyai Buka Permintaan, Edit Excel, serta Lihat Excel. Edit hanya untuk pembuat pada draft/returned; in_review/approved/published terkunci. `?view` memaksa mode baca walaupun pembuat masih boleh mengedit. Memodifikasi URL tidak melewati pemeriksaan status/izin di jalur simpan.
- Workspace Excel dirender sebagai main tersendiri tanpa chrome aplikasi. Identitas dokumen, kembali, simpan (bila berizin) dan unduh tetap tersedia. Mode baca tidak memuat ribbon edit. Area 1.000×1.000 dan virtualisasi dua sumbu dipertahankan.
- Pointer drag memakai capture pada grid, koordinat logis dari layout, range highlight/border, serta autoscroll. Header kolom/baris memilih hanya satu atau beberapa kolom/baris yang dituju, termasuk ketika area melintasi sel gabungan. Pemilihan sel biasa tetap diperluas untuk mencakup merge yang tersentuh. Autoscroll header terbatas pada sumbu yang sesuai. Shift+klik dan Go To tetap berfungsi. Aksi format maksimal 5.000 sel per operasi, sebagaimana batas sebelumnya.
- Sesudah format, merge, clipboard, atau Insert, fokus kembali ke sel aktif; bila anchor berada di luar DOM virtual, formula bar menjadi sasaran ketik untuk anchor yang sama. Double-click memungkinkan edit teks dalam sel. Tampilan angka memakai nilai raw ketika fokus dan nilai format ketika keluar.
- Font memakai combobox/listbox yang dapat dicari, mendukung keyboard dan font katalog serta template yang sudah ada. Ukuran diketik 1–409 pt dengan kelipatan 0,5. Target range dicatat saat kontrol menerima fokus agar blur setelah memilih sel lain tidak memformat sel yang salah.
- Tab Insert: Pictures (PNG/JPG), Symbol (palette dan teks Unicode), Text (teks sel). Kontrol lanjutan Excel yang belum diimplementasikan tidak ditampilkan. Gambar ditempatkan di anchor aktif, rasio dipertahankan. Batas 1 MB/gambar, 4.096 px/10 MP, 50 gambar/sheet, dan seluruh batas workbook sebelumnya tetap berlaku. Header dimensi diperiksa sebelum decode; file corrupt ditolak.
- Gambar baru disimpan sebagai DrawingML oneCellAnchor, image relationship, content type dan media part. Drawing/rels asli menjadi baseline, sehingga ekspor berulang tidak menggandakan gambar. Sheet tanpa drawing mendapat part baru; yang sudah mempunyai drawing mempertahankan isinya. Gambar pada batas terakhir boleh overhang tanpa memperbesar jumlah sel. Undo/redo menyimpan referensi immutable ke gambar baru; ekspor setelah undo menghapus media/generated drawing yang tidak dipakai. File versi tersimpan sebelumnya dan snapshot approval tidak ditimpa.
- Semua callback file async memeriksa aktor, record, route/mode, form, sheet, snapshot database, dan izin sebelum mutasi. Input gambar tidak memakai sumber jaringan, SVG, script atau layanan eksternal. Unduh snapshot belum disimpan tidak memicu konfirmasi meninggalkan editor.

## Verifikasi

`npm run check`, `npm test`, `npm audit --omit=dev`; browser terisolasi `browser-editor-ux.py`, `browser-workbook.py`, `browser-approval.py`, `browser-ribbon.py`, `browser-request-pdf.py`.

Tes UX membuktikan redirect tabel/aksi status, mode baca eksplisit dan route guard, workspace tanpa chrome, drag multi-format dan ketik tanpa klik ulang, anchor di luar viewport, header tidak meloncat pada sumbu lain, font searchable dan 13,5 pt, simbol tersimpan, PNG pada drawing lama/baru, gambar ALL1000 save/reload, undo/redo serta media yang tidak tertinggal setelah undo/ekspor. Regresi mencakup template asli, formula/style/print/image, file lokal, otorisasi kategori, review paralel, pengembalian, penerbitan manual, clipboard, batas area dan lebar layar.

Rujukan struktur gambar: [Microsoft OneCellAnchor](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.drawing.spreadsheet.onecellanchor), [Microsoft working with sheets](https://learn.microsoft.com/en-us/office/open-xml/spreadsheet/working-with-sheets). Tidak menambahkan kalkulasi formula penuh atau kolaborasi lintas perangkat; penyimpanan tetap prototipe browser-local.
