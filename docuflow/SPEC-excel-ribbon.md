# Ribbon Excel dan area 1.000 × 1.000

Permintaan user: setiap sheet menyediakan 1.000 baris dan 1.000 kolom; bentuk alat mengikuti ribbon Excel agar pengguna terbiasa. Perubahan ini menggantikan perluasan bertahap 100×26 hingga 1.000×100.

- Default sekaligus batas area editor adalah A1:ALL1000. Data template tetap sparse; membuka workbook tidak membuat satu juta record sel atau mengubah file resmi. Worksheet yang diedit menulis dimension A1:ALL1000 saat disimpan. Batas unggahan/ekstraksi ZIP, formula hanya baca, dan dokumen resmi terkunci tetap berlaku.
- Grid memvirtualkan kedua sumbu, mempertahankan spacer dan ukuran scroll seluruh sheet. Hanya sekitar 50 baris × 26 kolom (ditambah overscan sesuai viewport) berada di DOM. Merge yang terpotong pada salah satu/kedua sumbu tetap merujuk master asli; cakupan merge hanya dipetakan dalam viewport. Validasi overlap merge memakai bitmap maksimum 1 MB, menggantikan set string per sel.
- Ribbon Home: Clipboard, Font, Alignment, Number, Cells, Editing. Kontrol font/ukuran/bold/italic/underline, warna, border, perataan, wrap, merge/unmerge, format angka/persen/tanggal/teks, Copy/Cut/Paste, Clear, Find, row height dan column width berfungsi. View menampilkan/menyembunyikan gridlines dan formula bar. Name box, Go To, fx, serta input isi berada pada satu baris. Tab yang tidak diimplementasikan tidak ditampilkan.
- Clipboard sistem yang sudah diberi izin dibaca saat Paste. Clipboard aplikasi menjadi fallback. Paste... selalu menawarkan dialog tempel TSV eksternal meski sebelumnya menyalin dari aplikasi. CSV/TSV quoting, tab, multiline dan escaped quote ditangani; maksimal 1 MB/5.000 sel per operasi. Semua nilai dan sasaran divalidasi sebelum perubahan diterapkan; formula dan covered merge tidak dapat ditimpa. Teks formula yang ditempel tetap teks.
- Range formatting tetap maksimal 5.000 sel per aksi untuk membatasi kerja dan ukuran file. Sel tunggal pada bagian merge dinormalisasi ke master sambil mempertahankan tujuan scroll. Tab/Shift+Tab menavigasi kolom logis, melewati batas DOM virtual, serta wrap pada kolom ke-1.000. Clipboard fallback hanya tersedia bagi aktor sama dengan izin sumber yang masih berlaku.
- Ribbon dapat digeser horizontal di layar kecil; halaman tidak melebar. Kontrol edit dinonaktifkan sampai workbook selesai dimuat. Name box tetap tersedia pada mode baca. Semua mutasi memeriksa aturan draft/returned milik pembuat; persetujuan/penerbitan tidak berubah.

## Bukti dan batas

`npm run check`, `npm test` (termasuk parser clipboard dan batas ALL1000), serta browser terisolasi melalui `browser-ribbon.py`, `browser-workbook.py`, `browser-approval.py`, `browser-request-pdf.py`. Pengujian mencakup ALL1000 edit/save/reload/export, wheel kedua arah, merged master di luar viewport, style/font/image/formula/print settings, undo/redo, clipboard internal dan tempel eksternal, ukuran row/column, Find/View, keyboard, dokumen resmi hanya baca, dan 320/768/1024/1440/1918px.

Di desktop lokal 1918×1100, 1.257 textarea terpasang untuk satu juta sel logis; buka editor termasuk pembuatan draft terukur 225–287 ms pada beberapa pengujian. DOM dibatasi <3.500 sel pada fixture pengujian. Ini hasil sintetis lokal, bukan jaminan latensi perangkat lain. Regresi lama pada 100.000 sel memasang 9.901 textarea; beban kedua pengukuran berbeda sehingga angka tersebut bukan perbandingan latensi langsung.

Tidak ada dependensi baru. Fitur desktop Excel lengkap seperti kalkulasi rumus, chart/pivot, conditional formatting, dan macro tidak ditambahkan. Data tetap browser-local sebagaimana prototype sebelumnya.

Perubahan berikutnya menambah drag/header selection, focus restoration, font searchable/custom size, dan Insert gambar/simbol/teks; rincian serta bukti di SPEC-editor-ux.md.

Merge memindahkan nilai tunggal yang bukan rumus ke sel kiri atas ketika nilai berada di sel lain dalam rentang. Jika beberapa sel berisi data, isi sel kiri atas dipertahankan dan isi sel lain dihapus; Undo memulihkan XML seluruh sheet dan style. Shared formula yang kehilangan definisi sementara follower di luar area bertahan ditolak sebelum mutasi; array/data-table formula hanya bisa dihapus sebagai satu grup utuh. Rujukan: [CellFormula](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.spreadsheet.cellformula), [aturan array](https://support.microsoft.com/en-us/excel/rules-for-changing-array-formulas). CalcChain opsional dihapus setelah penghapusan rumus, termasuk override pada ekspor berulang dengan gambar; Excel diminta menghitung ulang. Tombol dan keyboard memakai satu riwayat yang menyimpan pilihan/range.

Shortcut dalam workspace: Ctrl/Cmd+Z Undo, Ctrl/Cmd+Y atau Ctrl/Cmd+Shift+Z Redo, Ctrl/Cmd+S Simpan, Ctrl/Cmd+B/I/U format. Pencarian/font/ukuran mempertahankan native text Undo, dialog tidak ditangani, dan mode baca tidak bermutasi. Tes browser-merge.py membuktikan nilai tunggal di luar pojok pada zoom 55%, nilai nol, shared/rich text, formula removal/restore, image+export dua kali, grup shared/array, format shortcut, save/reload dan readonly.
